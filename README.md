# Export All Sheets to CSV

![](./screenshot.png)

Extension for Libreoffice Calc to export all sheets in a spreadsheet to separate CSV files.

Adds a button "Export CSV Sheets" to Calc, between "Export Directly as PDF" and "Print".

CSV files will be named "{spreadsheet}-{sheet}.csv" and saved alongside the spreadsheet file.

CSV export options (delimiters etc.) are currently not supported.

## Install

1. Download latest release
1. Open it with Libreoffice
1. Restart Libreoffice
